# Spieldokumentation

Stand 15. November 2026.

- `DarkestCards3D_Spieldokumentation.pdf` ist die fertig gesetzte Lesefassung mit Inhaltsverzeichnis, Kapitelmarken, allen 118 Sammelkarten und dem Prüfbericht.
- `DarkestCards3D_Spieldokumentation.md` enthält dieselben Inhalte als bearbeitbare Textfassung.
- `audit/test-results-reviewed.json` enthält die abschließenden Ergebnisse. Ursprüngliche Logs, gezielte Nachprüfungen und die Quellcode-Prüfsummen bleiben als Belege erhalten.
- `qa/document-check.json` protokolliert die Dokumentprüfung. Seitenbilder im QA-Ordner sind nur Vorschauen für die Layoutkontrolle.

Die Dokumentation beschreibt den lokalen Projektstand. Offene Tests und die noch ausstehende reale Steam- und Exportabnahme sind im Prüfbericht ausdrücklich eingeordnet. Produktionsmechaniken wurden bei dieser Dokumentationsaufgabe nicht verändert.

Für eine spätere Aktualisierung befinden sich Textvorlage und Erzeugung unter `tools/documentation_audit`. Kartentabellen werden aus dem Katalog erzeugt; Regeltexte müssen bei geänderten Mechaniken erneut mit dem tatsächlichen Code abgeglichen werden.
